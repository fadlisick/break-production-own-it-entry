# Break Production, Own It

Entry for the make.fun competition "Break Production, Own It"
(`u-ricoxyz-break-production-own-it-be78a994`).

honest thing an AI agent prints the instant it breaks production.

86 characters, single line, under the 200-character gate. Run it with
